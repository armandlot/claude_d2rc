Données personnelles et confidentialité

D2R Run Counter est un projet communautaire non officiel. Il est conçu pour collecter le strict minimum.

Ce qui est enregistré

  • Vos données de jeu : personnages, routes, sessions de farm et objets notés.
  • Si vous utilisez « Se connecter avec Google » : un identifiant de compte, sous forme d'empreinte non réversible (HMAC-SHA256) de l'identifiant anonyme fourni par Google, avec les dates de création et de dernière connexion.
  • Votre session de connexion : un cookie technique, dont le serveur ne garde que l'empreinte.

Ce qui n'est jamais demandé ni enregistré

  • Ni adresse e-mail, ni nom, ni photo : seule l'autorisation « openid » est demandée à Google.
  • Aucun mot de passe : l'authentification est faite par Google.
  • Aucun jeton d'accès Google conservé, aucun traceur publicitaire, aucune revente.

Où sont les données

Dans votre navigateur (pour l'usage hors ligne) et dans une base Cloudflare D1 liée à l'application. Le cookie de session expire après 90 jours sans utilisation.

Vos droits

Le menu de synchronisation propose « Supprimer mon compte et mes données » : le compte, ses sessions de connexion et toutes ses données de jeu sont alors effacés du serveur et de l'appareil. Vous pouvez aussi retirer l'accès de l'application depuis votre compte Google (Sécurité → Applications tierces).
